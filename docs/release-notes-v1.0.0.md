# Release Notes v1.0.0

## Japanese

Personal Page Tweaker の初回Chrome Web Store公開に向けたリリースです。

- サイト別のCSSとJavaScript、3つの実行タイミング、広い編集欄と内容のあるタブの印を搭載。
- サイトごとのアクセス許可、除外URL、フレーム指定、ローカルバックアップに対応。
- ストア用アイコン、紹介画像、公開用のプライバシーポリシー・権限説明を追加。
- Exportは通常のファイル保存を使い、downloads権限を削除。
- 既存の設定ID、保存キー、v1/v2バックアップの読み込みとv3形式を維持。

## English

This release prepares Personal Page Tweaker for its first Chrome Web Store listing.

- Per-site CSS and JavaScript, three independent execution timings, a spacious editor and non-empty tab indicators.
- Individual site permissions, URL exclusions, frame controls and local backup/restore.
- Store icons, screenshots, a public privacy policy and permission justifications.
- Standard file export without the downloads permission.
- Existing setting IDs and storage are preserved; v1/v2 backups remain importable and v3 remains the export format.

The settings interface is in Japanese. Chrome 138 or later is required. JavaScript requires the extension's “Allow User Scripts” toggle.
