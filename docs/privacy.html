PRIVACY POLICY

プライバシーポリシー

最終更新: 2026年11月3日 · 対象: Personal Page Tweaker 1.0.0

Personal Page Tweakerは、ユーザーが用意したCSSとJavaScriptで、許可したサイトのページをカスタマイズするChrome拡張です。この目的に必要な情報を端末内で扱います。拡張本体から開発者のサーバーへデータを送信する処理はありません。

扱う情報と目的

  • ページのURL・ホスト名: 閲覧中のサイトをポップアップに表示し、対象URL・除外URLに合うかを端末内で照合します。閲覧履歴APIは使わず、閲覧履歴のログも保存しません。
  • ページの内容: 許可されたページにCSSを適用し、登録されたJavaScriptで見た目や動作を変更します。JavaScriptが読み取る内容や行う処理は、ユーザーが登録したコードによって決まります。
  • 設定: 設定名、対象・除外URLの条件、CSS、JavaScript、有効状態、実行環境・タイミング・フレーム設定、作成・更新日時を保存します。
  • ユーザーが選択したファイル: JSONバックアップと.user.jsを取り込む際に、そのファイルの内容を読み込みます。ファイルを自動探索したり、外部から自動取得したりはしません。

保存・バックアップ・削除

設定はこのChromeプロファイルの chrome.storage.local に保存します。開発者のクラウドやChromeの同期ストレージには保存しません。Importで全設定を置き換える前には、直前の設定を復旧用に1世代分保存します。

Exportはユーザーの操作でJSONファイルを端末へ保存します。バックアップにはコードやURL条件が含まれます。ファイルを共有するかどうかはユーザーが決めます。

個々の設定は編集画面から削除できます。復旧用コピーを含むすべての拡張保存データは、拡張のストレージを消去するか拡張をアンインストールすることで削除できます。設定の削除だけでは以前のImport復旧用コピーは消えない場合があります。Export済みファイルは別に削除してください。

ユーザー提供のJavaScript

ユーザーが編集欄に入力したコード、または明示的に取り込んだファイル内のコードを chrome.userScripts APIで実行します。拡張機能の管理処理はすべて配布パッケージ内にあります。CDN、開発者サーバー、スクリプト配布URLなどから実行コードを自動で取得・更新しません。

登録したJavaScriptは、許可された対象ページの情報を読み取り、コードに従って外部サービスへ送信することがあります。送信先・内容はそのコードによって決まります。これは拡張本体による開発者への収集・送信とは別です。内容を確認したコードだけを登録してください。

独立した実行環境が通常の選択です。ユーザーが選ぶ「ページと同じ環境」では、ページのJavaScriptと同じ環境で動きます。ユーザースクリプト向けの拡張APIメッセージングは有効にしていません。

共有・解析・Limited Use

拡張本体には、広告、解析、操作履歴の追跡、データの販売、データブローカーへの提供、信用評価や融資への利用機能はありません。アカウント登録やログインもありません。ユーザーデータは、ページのカスタマイズと設定管理という単一目的だけに使います。

Google APIから受け取る情報の利用は、Limited Use要件を含むChrome Web Store User Data Policyに従います。

この公開サイトはGitHub Pagesで配信しています。ページの閲覧やGitHub Issuesの利用にはGitHubのプライバシーに関する説明も適用されます。拡張本体はこのサイトをバックグラウンドで読み込みません。

Privacy Policy — English

Last updated: November 3, 2026. Applies to Personal Page Tweaker 1.0.0.

Personal Page Tweaker customizes individually permitted websites using CSS and JavaScript supplied by the user. Bundled extension code sends no data to a developer-operated server.

Information handled and purpose

Current and permitted page URLs/hostnames are used locally to show the current site and match inclusion/exclusion rules. No browser-history API or browsing-history log is used. Permitted page content is modified by CSS and registered JavaScript. What a user script reads or does depends on that script.

Stored settings include rule names, URL patterns, exclusions, CSS, JavaScript, enabled states, execution world, timing and frame options, and creation/update timestamps. A JSON or .user.js file is read only when the user selects it for import.

Storage, retention and deletion

Settings stay in chrome.storage.local in the user's Chrome profile. They are not sent to developer cloud storage or Chrome sync storage. One previous settings collection is kept locally as a recovery copy before a full JSON import. Export creates a local JSON file containing settings and code when the user requests it.

Rules can be deleted individually. A prior import recovery copy may still contain deleted rules until replaced or cleared. Clear extension storage or uninstall the extension to remove all its stored data. Delete exported backup files separately.

User-supplied code and network requests

Only code explicitly entered or imported by the user is run with chrome.userScripts. All extension management logic is bundled. The extension does not automatically download or update executable code from URLs, CDNs or developer servers. User scripts may read permitted page information and make requests to destinations specified in their own code. This is distinct from the bundled extension's data handling. Users should review code before registering it.

The default is an isolated user-script world. Users can opt into the page's main world. User-script messaging to extension APIs is not enabled.

Sharing and limited use

The extension has no account/login, advertising, analytics, interaction tracking, data sale, data-broker sharing, credit-scoring or lending functions. Data is used only for page customization and settings management.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Website and contact

This website is hosted by GitHub Pages. GitHub's privacy statement also applies to website visits and use of GitHub Issues. The extension does not load this site in the background. Contact project support or x013318908@gmail.com. Information voluntarily provided in a support request is used to respond to that request.
